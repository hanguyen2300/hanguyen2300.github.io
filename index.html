Personal Workspace MCP

This is a private, single-user tool. It connects the owner's own Google account to a local AI assistant (via the Model Context Protocol) so the owner can read and manage their own Gmail, Drive, Calendar, Docs, Sheets, Slides, Forms, Tasks and Contacts.

It is not a public service. It runs only on the owner's computer, and no one else can sign up or use it.
