Privacy Policy — Personal Workspace MCP

Last updated: October 11, 2026

Who uses this app

This app is used only by its owner to access the owner's own Google account. It is not offered to the public.

What data is accessed

With the owner's consent, the app accesses Google user data in Gmail, Drive, Calendar, Docs, Sheets, Slides, Forms, Tasks, Contacts and Apps Script, only to carry out actions the owner requests.

Where data is stored

OAuth tokens are stored only on the owner's local computer, in files readable only by the owner's user account. Google user data is not stored on any server operated by this app, and the app does not run any server reachable from the internet.

Sharing

Google user data is not sold, shared with third parties, used for advertising, or used to train generalized AI or machine-learning models. There is no analytics or tracking.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, and local tokens can be deleted from the owner's computer.
